# 战术练枪场 (Tactical Aim Trainer)

战术射击类（无畏契约风格）练枪软件。目标是做到：

- 移动和射击手感接近端游：急停、静步、首发精准、跑打散布
- 假人可以放在任意点位，能被一枪爆头，也能开枪还击
- 地图用白模搭建，掩体比例正确
- 输入延迟尽量低，帧率尽量高

> 本项目与 Riot Games 无关，不包含任何官方素材。地图全部是原创白模，只参考常见的点位结构和尺寸比例。

## 网页原型

用 Chrome 或 Edge 直接打开 `web-prototype/index.html` 即可，不需要安装任何东西。three.js 从 cdnjs 加载，所以首次打开需要联网。

- 三张原创地图：靶场、双点（A 道 / 中路 / B 道）、庭院
- 三种模式：定点甩枪、移动靶（ADAD 横跳）、对枪（假人按难度的反应时间还击）
- 灵敏度换算与端游一致：每个鼠标计数转 `0.07° × 灵敏度`，水平视野 103°
- 可自定义准星，结算显示击杀、爆头率、命中率、平均击杀耗时

按键：`WASD` 移动 · `Shift` 静步 · `C` 下蹲 · `空格` 跳跃 · `左键` 射击 · `R` 换弹 · `Esc` 暂停

浏览器的帧率最高只能等于显示器刷新率，也会多出一些合成延迟，所以网页版只能做到接近端游。引擎版就是为了解决这个问题。

## Unity 版

需要 Unity 6（推荐 6000.0 LTS 的最新补丁版本，不低于 6000.0.58f2）。

1. Unity Hub → **Add** → **Add project from disk** → 选择仓库里的 `unity` 文件夹
2. 菜单栏 **AimTrainer → 创建移动测试场景（第一阶段）**
3. 点 **Play**，再点一下 Game 视图锁定鼠标

按键、测试场景、实现原理、参数和验收步骤见 [`docs/phase1-movement.md`](docs/phase1-movement.md)。

## 原型当前参数

下面是网页原型代码里实际用的数值，是根据手感调出来的，**不是官方数据**。Unity 版以这些数值为起点（唯一的改动是能直接走上的台阶高度改为 0.4 m）。

### 移动

| 参数 | 数值 | 说明 |
|------|------|------|
| 跑步速度 | 5.4 m/s | 手持步枪 |
| 静步速度 | 跑步 × 0.52 ≈ 2.8 m/s | 按住 Shift |
| 下蹲速度 | 跑步 × 0.42 ≈ 2.3 m/s | |
| 加速 | 指数逼近目标速度，速率 13 /s | `v += (目标 − v) · (1 − e^(−13·dt))` |
| 松键减速 | 指数衰减，速率 18 /s | 从 5.4 降到 1.6 m/s 约 68 ms |
| 反向急停 | 按反方向键，速率 13 /s | 从 5.4 降到 1.6 m/s 约 33 ms，比单纯松键快一倍 |
| 起跳速度 / 重力 | 6.0 m/s / 20 m/s² | 跳高 0.9 m，滞空 0.6 s |
| 眼睛高度 | 站立 1.60 m，下蹲 1.15 m | |
| 自动上台阶 | ≤ 0.5 m | |

### 射击（步枪）

| 参数 | 数值 |
|------|------|
| 射速 | 9.75 发/秒 |
| 弹匣 / 换弹 | 25 发 / 2.5 s |
| 伤害 | 头 160 · 身体 40 · 腿 34（假人 150 血，爆头一枪死） |
| 首发散布 | 0.12° |
| 连射散布 | 每发 +0.22°，上限 2.2°；停火 0.4 s 后重置 |
| 弹道上跳 | 第 3 发起每发上抬 0.5°，最多 8 次；第 11 发起左右摆动 ±1.4° |
| 移动惩罚 | 水平速度 > 1.6 m/s 时，加 `速度 × 1.1°` |
| 空中惩罚 | +7° |
| 下蹲 | 散布 × 0.85 |

目前静步速度 2.8 m/s 也超过 1.6 m/s 的门槛，所以静步开枪和跑打用的是同一条惩罚曲线，只是数值小一些。第二阶段会把“跑打 / 静步 / 急停”拆成三档分别调。

### 假人（对枪模式）

| 难度 | 反应时间 | 命中率 | 爆头率 | 射击间隔 |
|------|---------|--------|--------|---------|
| 简单 | 480 ms | 30% | 8% | 0.50 s |
| 普通 | 320 ms | 45% | 18% | 0.38 s |
| 困难 | 220 ms | 60% | 28% | 0.30 s |
| 职业 | 160 ms | 72% | 42% | 0.24 s |

实际反应时间在表中数值的 85%–125% 之间随机。玩家水平速度超过 2.5 m/s（跑步和静步都算）时，假人命中率 × 0.7；距离超过 30 m 时 × 0.8；玩家在空中时 × 0.8。
