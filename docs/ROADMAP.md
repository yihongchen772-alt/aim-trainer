# 开发路线

引擎版分五个阶段做。每个阶段都有验收标准，达到了再进入下一阶段。数值的起点见 README 里的“原型当前参数”。

开发原则：

- **先手感，后美术。** 墙和掩体一律用灰色方块，假人用红色胶囊体。贴图和材质放到最后。
- **数值集中管理。** 速度、散布、伤害、反应时间都放进一个配置资源（Unity 的 ScriptableObject 或 Unreal 的 DataAsset），不要写死在代码里，方便反复调手感。
- **头部判定单独做。** 头部碰撞体独立出来，并且比视觉模型稍大一圈，打起来更爽快。

---

## 第一阶段：第一人称移动控制器

目标：移动手感接近端游，包括静步和急停。

状态：代码已完成（Unity 6），待在 Unity 中验收。说明和验收步骤见 [`phase1-movement.md`](phase1-movement.md)。

内容：
- 跑步、静步（Shift）、下蹲、跳跃、重力、上台阶
- 自己算速度，不依赖物理引擎的摩擦力：地面上用指数逼近目标速度，松键和反向键分别用不同的减速速率
- 鼠标视角：原始输入，灵敏度公式 `每计数角度 = 0.07° × 灵敏度`，水平视野固定 103°
- 调试面板：实时显示水平速度，以及当前是否处于“可精准射击”状态

验收标准：
- [ ] 跑步 5.4 m/s、静步约 2.8 m/s，速度表读数和配置一致
- [ ] 跑步中松开方向键，约 70 ms 内速度降到 1.6 m/s 以下
- [ ] 按反方向键急停，约 35 ms 内降到 1.6 m/s 以下
- [ ] 把游戏内灵敏度填进来，转 360° 需要的鼠标距离和端游一致

## 第二阶段：射击与弹道

目标：射线判定（Hitscan）、后坐力、散布，区分三种开枪状态。

内容：
- 从摄像机发射射线，命中后按部位（头 / 身体 / 腿）结算伤害
- 后坐力分两部分：固定的弹道图案（上跳、左右摆动）+ 随机散布圆
- 精度分三档：跑打、静步开枪、急停后站立开枪，各自有独立的散布惩罚
- 连射计数与停火恢复时间
- 弹孔和弹道线，方便看清弹道

验收标准：
- [ ] 急停后站立开枪的首发落在准星中心（散布 ≤ 0.15°）
- [ ] 跑打、静步、站立三种状态的散布明显不同，并且可以在配置里单独调
- [ ] 对墙压枪扫射，弹孔形成稳定可重复的图案
- [ ] 射击判定和画面渲染帧率无关（低帧率下射速不变）

## 第三阶段：假人 AI 与预瞄练习

目标：假人能放在任意点位，有血量，能还击。

内容：
- 假人可以在编辑器里拖到任意位置，也可以从点位列表随机生成
- 血量 150：头部一枪死，身体多枪
- 视野圆锥：玩家进入假人前方的视野范围，并且中间没有墙挡着，才算“看到”
- 反应延迟（默认 0.3 s，按难度可调）后，向玩家发射射线造成伤害
- 可选行为：原地不动、左右横跳、从掩体后探头

验收标准：
- [ ] 爆头一枪击杀，身体需要 4 枪
- [ ] 玩家在假人视野圆锥外，或者被掩体挡住时，假人不开枪
- [ ] 从玩家出现在视野里到假人第一枪，间隔等于设定的反应时间
- [ ] 结算显示击杀数、爆头率、命中率、平均击杀耗时

## 第四阶段：白模地图

目标：用引擎自带的几何工具搭出比例正确的白模场景。

内容：
- 先定尺寸标准：人物身高、眼睛高度、墙高、蹲下能躲住的掩体高度、通道宽度
- Unity 用 ProBuilder，Unreal 用自带的建模工具（Modeling Mode）
- 先做一个局部场景（例如一个包点），点位结构参考常见战术射击地图，但几何体全部自己搭

验收标准：
- [ ] 站立时能从矮掩体后露出头，下蹲时完全躲住
- [ ] 通道宽度能让两名角色并排通过
- [ ] 假人点位标记在地图里，可以一键开始预瞄练习

## 第五阶段：延迟与帧率优化

目标：鼠标跟手程度和帧率接近端游竞技水平。

内容：
- 关闭会增加延迟或拖低帧率的渲染功能：动态模糊、景深、时间性抗锯齿（TAA）、垂直同步、复杂的动态阴影和全局光照
- 关闭帧率上限，提供“不锁帧”选项
- 鼠标使用原始输入，在每帧渲染前读取并应用视角
- 显示帧率和帧时间（ms），用于测试

验收标准：
- [ ] 中端显卡上白模场景稳定 300 FPS 以上
- [ ] 帧时间曲线平稳，没有明显卡顿尖峰
- [ ] 关闭垂直同步后，鼠标转动没有可感知的拖滞
