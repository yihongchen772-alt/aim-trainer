## 当前状态

- **能用的**：在 Unity 6000.0.58f2 里打开项目、自动生成场景（已由用户确认）。
- **还没验证的**：实际游玩手感、假人行为、菜单在不同分辨率下的显示、打包后的程序。所有代码只做过 Unity 2021 引用库的编译检查和 .NET 单元测试（76 个）。
- **已知限制**：仿端游地图是凭印象搭的近似布局，比例不精确；后坐力是按走势近似，不是逐发复刻。

## 参考：SpikeAtlas 的功能

用户推荐了 [SpikeAtlas](https://spikeatlas.com/)（无畏契约预瞄模拟器，网页版 + 桌面客户端）。它的主要功能：

| 功能 | SpikeAtlas 的做法 | 我们现在 |
|------|------------------|---------|
| 地图 | 13 张地图，使用官方地图模型（按 Riot 的 Legal Jibber Jabber 政策） | 4 张仿端游白模 + 2 张原创 |
| 区域与点位 | 每张图按区域整理，例如亚海悬城 22 个区域：A 侧 Lobby / Main / Wine / Tree / Garden / Window / Rafters / Site，中路 Bottom / Catwalk / Courtyard / Market / Pizza / Link / Top，B 侧 Lobby / Main / Boat House / Site | 只做了单个包点，点位有中文名但没有区域划分 |
| 自由跑图 | 整张地图随便走 | 只有单个包点 |
| 预瞄训练 | 沿路线推进，假人在“真正看到玩家后”按难度延迟开枪；三档难度 | 有“预瞄清点”，所有点位同时出现 |
| 架枪训练 | 玩家守一个位置，假人从入口冲出来 | 没有 |
| 背闪训练 | 闪光遭遇点：转身躲闪、打掉诡眼、回头接敌 | 没有 |
| 防守训练 / 模拟实战 | 测试中 | 对枪模式接近 |
| 设置 | 灵敏度、键位、画面、准星、音频，自动保存 | 灵敏度、准星、音量、帧率（键位不能改） |
| 灵敏度测试工具 | 独立页面 | 菜单里显示 360° 距离 |
| 训练记录 | 训练历史、继续上次训练 | 每种设置只记一个最好成绩 |
| 攻略 | 预瞄、急停、搜点、背闪、角度优势、听声 | 各阶段技术文档，没有训练攻略 |

**素材说明**：SpikeAtlas 用的是官方地图模型。我们不提取、不复制它或游戏里的任何模型和贴图，地图仍然用白模自己搭；功能和训练方法可以参考。

## 下一步计划（参考 SpikeAtlas）

按对练枪帮助大小排序：

1. **完整地图 + 区域划分**：先把亚海悬城做成整张图（A / 中路 / B 三路），按上面的 22 个区域命名；每个区域在调试面板和小地图上显示名字。
2. **预瞄路线训练**：沿固定路线推进，每个拐角的假人在你进入它视野时才出现（或才开始反应），记录每个点位的反应时间，结束后显示哪个角度最慢。
3. **架枪训练**：玩家选一个守点位置，假人从入口随机冲出 / 探头，练反应和爆头线。
4. **训练记录**：保存每局的时间、地图、模式、成绩，菜单里能看历史和“继续上次训练”。
5. **小地图**：屏幕角落显示俯视图、玩家位置和朝向、假人点位。
6. **键位设置**：可以改移动、蹲、静步、跳、换弹的按键。
7. **背闪训练**：随机方向出现闪光预警，转身躲开后回头接敌。
8. 其余地图依次做成整图。
