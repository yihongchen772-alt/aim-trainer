## 当前状态

- **能用的**：在 Unity 6000.0.58f2 里打开项目、自动生成场景（已由用户确认）。
- **还没验证的**：实际游玩手感、假人行为、菜单在不同分辨率下的显示、打包后的程序。所有代码只做过 Unity 2021 引用库的编译检查和 .NET 单元测试（87 个）。
- **已知限制**：仿端游地图是凭印象搭的近似布局，比例不精确；后坐力是按走势近似，不是逐发复刻。

## 参考：SpikeAtlas 的功能

用户推荐了 [SpikeAtlas](https://spikeatlas.com/)（无畏契约预瞄模拟器，网页版 + 桌面客户端）。它的主要功能：

| 功能 | SpikeAtlas 的做法 | 我们现在 |
|------|------------------|---------|
| 地图 | 13 张地图，使用官方地图模型（按 Riot 的 Legal Jibber Jabber 政策） | ✅ 亚海悬城真实地图（同样的模型来源）；另有白模整图、4 张仿端游包点和 2 张原创 |
| 区域与点位 | 每张图按区域整理，例如亚海悬城 22 个区域：A 侧 Lobby / Main / Wine / Tree / Garden / Window / Rafters / Site，中路 Bottom / Catwalk / Courtyard / Market / Pizza / Link / Top，B 侧 Lobby / Main / Boat House / Site | ✅ 亚海悬城整图 24 个区域，小地图下方显示所在区域；包点图还没有划分区域 |
| 自由跑图 | 整张地图随便走 | ✅ 亚海悬城整图可以走遍三路 |
| 预瞄训练 | 沿路线推进，假人在“真正看到玩家后”按难度延迟开枪；三档难度 | ✅ 预瞄清点可选路线（亚海悬城 3 条）；假人看到你后按反应时间开枪（四档难度）；结算显示每个点位的耗时和被击杀次数 |
| 架枪训练 | 玩家守一个位置，假人从入口冲出来 | ✅ 架枪模式，亚海悬城 3 个位置，每个 3 个入口 |
| 背闪训练 | 闪光遭遇点：转身躲闪、打掉诡眼、回头接敌 | 没有 |
| 防守训练 / 模拟实战 | 测试中 | 对枪模式接近 |
| 设置 | 灵敏度、键位、画面、准星、音频，自动保存 | ✅ 灵敏度、键位、准星、音量、帧率、小地图 |
| 灵敏度测试工具 | 独立页面 | 菜单里显示 360° 距离 |
| 训练记录 | 训练历史、继续上次训练 | ✅ 最近 30 局记录，一键继续上次训练 |
| 小地图 | 有 | ✅ 根据场景自动画出俯视图，显示位置、朝向、正在看你的假人 |
| 攻略 | 预瞄、急停、搜点、背闪、角度优势、听声 | 各阶段技术文档，没有训练攻略 |

**素材说明**：SpikeAtlas 用的是官方地图模型。我们不提取、不复制它或游戏里的任何模型和贴图，地图仍然用白模自己搭；功能和训练方法可以参考。
