# 第二阶段：射击系统与弹道

目标：射线判定（Hitscan），后坐力和散布，区分“跑动开枪”“静步开枪”“急停后开枪”三种精度。

代码：`Assets/AimTrainer/Scripts/Weapons/`。参数在 `Assets/AimTrainer/Settings/DefaultRifle.asset`（生成场景时自动创建），运行中改了立即生效，退出 Play 后保留。

## 一发子弹怎么算

每次开枪按下面的顺序计算：

1. **连射计数**：这是连续第几发（`SprayTracker`）。
2. **散布**：基础散布（随连射变大，蹲下变小）+ 移动惩罚（看当前水平速度）。
3. **弹道图案**：第几发对应固定的上跳和左右摆动（后坐力，可以压枪抵消）。
4. **随机偏移**：在“散布”半径的圆内均匀随机取一个点。
5. **射线**：从摄像机沿“瞄准方向 + 弹道图案 + 随机偏移”发射，最远 200 米。打中挂了 `Hitbox` 的碰撞体就按部位结算伤害，打中墙留弹孔。

射线从摄像机位置发出，起点在玩家自己的碰撞体里面，物理引擎不会命中包含起点的碰撞体，所以不会打到自己。

## 三档精度

移动惩罚只看水平速度，叠加在基础散布上：

| 状态 | 水平速度 | 额外散布 |
|------|---------|---------|
| 站定 / 急停后 | ≤ 1.6 米/秒 | 0° |
| 静步 | 1.6 → 2.81 米/秒 | 0° → 1.6° 线性增加 |
| 跑动 | 2.81 → 5.4 米/秒 | 1.6° → 6° 线性增加 |
| 空中 | 任意 | 8° |

“急停后开枪”就是利用第一阶段的急停：反向急停约 33 毫秒就能把速度降到 1.6 米/秒以下，这时开枪没有任何移动惩罚。

准星正下方的小方点会实时显示当前状态：**绿 = 站定 / 急停后**，**黄 = 静步**，**红 = 跑动或空中**。可以在菜单里关掉。

## 基础散布与后坐力

| 参数 | 默认值 | 说明 |
|------|--------|------|
| firstShotSpread | 0.12° | 静止时第一发的散布 |
| sprayGrowthPerShot | 0.22° | 连射每多一发增加的散布 |
| maxSpraySpread | 2.2° | 连射散布上限（不含移动惩罚） |
| crouchMultiplier | 0.85 | 完全蹲下时基础散布乘以它 |
| climbStartShot / climbPerShot / climbShots | 第 3 发 / 0.5° / 8 发 | 从第 3 发开始每发上跳 0.5°，最多 8 次，共 4° |
| swayStartShot / swayAmplitude | 第 11 发 / ±1.4° | 之后改为左右摆动 |
| sprayRecoveryDelay | 0.12 秒 | 停火超过这么久才开始恢复连射计数 |
| sprayRecoveryRate | 30 发/秒 | 恢复速度：停火 0.45 秒左右，10 发连射完全恢复 |

所以：
- **点射**（间隔 0.3 秒以上）每一发都是“第一发”，散布只有 0.12°。
- **扫射**前两发很准，从第 3 发开始往上跑，第 11 发之后左右摆。往下拉鼠标就是压枪。
- 弹道图案（上跳、左右摆）是固定的，可以对着墙练压枪，弹孔会留在墙上（最多 96 个）。但连射时随机散布会涨到 2.2°，比左右摆的幅度还大，所以两次扫射的大致走势相同，单个弹孔的位置不同。

准星本身不会跟着后坐力移动，后坐力只影响子弹的方向。开枪时枪模会往后顶一下，只是画面效果。

## 射速与弹匣

| 参数 | 默认值 |
|------|--------|
| 射速 | 每秒 9.75 发（全自动） |
| 弹匣 | 25 发，备弹无限 |
| 换弹 | 2.5 秒；打空自动换弹，也可以按 R |

射速和帧率无关（`FireClock`）：按住左键时，第 k 发固定出现在“开始时间 + k × 间隔”，一帧里到期几发就打几发，30 帧和 500 帧打出的子弹数完全一样。卡顿时一帧最多补打 4 发。

点击画面锁定鼠标的那一下不会开枪，必须松开左键再按。

## 伤害与判定框

| 部位 | 伤害 | 打 150 血目标需要 |
|------|------|------------------|
| 头 | 160 | 1 发 |
| 身体 | 40 | 4 发 |
| 腿 | 34 | 5 发 |

每个部位是独立的碰撞体，挂 `Hitbox` 组件标明是头、身体还是腿。头部判定框半径 0.18 米，比看到的头（0.15 米）大 20%，打起来更有“爽快感”。可以设置距离衰减（`falloffDistance`），默认关闭。

## 打中的反馈

- 爆头：清脆的“叮” + 黄色命中标记
- 身体：短促的“嗒” + 白色命中标记
- 击杀：额外一声上扬音 + 红色命中标记，假人向后倒下
- 墙面：弹孔
- 每一发都有一条很短的弹道线

所有音效都是运行时用代码合成的，不需要音频文件。

## 改成别的枪

在 Project 窗口右键 → **Create → AimTrainer → Weapon** 新建一个枪械资源，改好参数，再把场景里 `Player` 物体上 **Hitscan Weapon** 组件的 Definition 换成它。例如：

- 半自动步枪：`automatic` 关掉，`roundsPerSecond` 改成 4.5，`bodyDamage` 改大。
- 冲锋枪：射速调高、`walkSpread` 和 `runSpread` 调小（跑打更准），设置 `falloffDistance`。

## 验收

对应 `docs/ROADMAP.md` 第二阶段：

1. 站定后对 10 米外的墙点射：弹孔应该基本叠在一起（0.12° 的散布在 10 米处偏差不超过约 2 厘米）。
2. 跑动、静步、急停后各开几枪：弹孔散开的程度应该明显不同，准星下的小方点分别是红、黄、绿。
3. 对墙按住左键扫射 25 发：弹孔整体先往上爬约 4°，第 11 发以后左右散开。想看清纯弹道图案，可以把 `Settings/DefaultRifle.asset` 的 Max Spray Spread 和 Spray Growth Per Shot 临时设为 0，这时每次扫射的弹孔几乎完全重合（看完记得改回来）。
4. 把帧率上限分别设成 60 和不限，按住左键 1 秒：都应该打出 10 发。
