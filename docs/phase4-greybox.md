# 第四阶段：地图与白模

目标：用几何体搭出比例正确的掩体和通道，在上面练对枪和预瞄。

官方地图的模型和布局属于游戏公司，这里不复制任何一张真实地图。“A 点”是按常见战术射击地图的攻点结构**原创**的白模：一条大道、一条连接、包点区、高台和防守方通道。

## 尺寸标准

数值和第一阶段的角色尺寸配套（1 个 Unity 单位 = 1 米）：

| 项目 | 尺寸 | 原因 |
|------|------|------|
| 角色身高 | 站立 1.8 米，下蹲 1.3 米 | 碰撞胶囊高度 |
| 眼睛高度 | 站立 1.6 米，下蹲 1.15 米 | 摄像机高度 |
| 头部 | 中心 1.6 米，半径 0.15 米 | 站立时头顶约 1.75 米 |
| 角色半径 | 0.3 米 | 碰撞胶囊半径 |
| 墙高 | 4 ~ 6 米 | 高于跳跃能看到的高度（1.6 + 0.9 = 2.5 米），视线完全挡住 |

## 用 ProBuilder 自己搭地图

生成的场景是用 Unity 自带的立方体拼的，适合快速出白模。想自由建模（斜面、开窗、拱门）就用 ProBuilder：

1. **安装**：**Window → Package Manager** → 左上选 **Unity Registry** → 搜索 **ProBuilder** → **Install**。
2. **打开工具栏**：**Tools → ProBuilder → ProBuilder Window**。
3. **建形状**：点 **New Shape**，选 Cube / Stairs / Arch / Door 等，在 Scene 视图里拖出来。Inspector 里可以直接输入精确尺寸。
4. **编辑**：工具栏切换到面（Face）模式，选中面后按住 Shift 拖动可以挤出（Extrude），也可以用 **Subdivide**、**Insert Edge Loop** 切分。
5. **对齐网格**：**Edit → Grid and Snap Settings**，把移动步长设成 0.5 或 0.25 米，摆掩体时尺寸更容易对齐。
6. **碰撞**：ProBuilder 物体默认带 Mesh Collider，射线和移动都能正常碰撞，不需要额外处理。
7. **颜色**：把 `Assets/AimTrainer/Generated` 里的材质（Wall、Block、Cover、Platform）拖到物体上，保持和生成场景一致的白模配色。

## 做一张自己的地图

1. 打开一个生成好的场景（比如 A 点），**File → Save As**，存成新名字，例如 `Assets/AimTrainer/Scenes/MyMap.unity`。另存后再怎么改，都不会被“重新生成全部场景”覆盖。
2. 删掉或修改 `Level` 下的几何体，用立方体或 ProBuilder 搭新地图。
3. 移动 `PlayerSpawn` 物体到出生点（蓝色箭头是朝向）。从 A 点另存的场景里还有一个 `AimModeSpawn` 物体（定点甩枪和移动靶的出生点），也要移到新地图里；不需要单独的出生点就删掉它，所有模式都会用 `PlayerSpawn`。
4. 在 `Bots` 下增删 **Bot Spawn Point**（固定点位）和 **Bot Spawn Area**（随机刷新区域），方法见第三阶段文档。开始训练时会自动找到场景里所有的点位和区域，不需要手动登记。
5. 加到菜单里：打开 `Assets/AimTrainer/Scripts/Game/SceneCatalog.cs`，在 `Training` 数组里加一行 `new Entry("MyMap", "我的地图", "说明")`；再在 **File → Build Profiles** 里把场景加入打包列表。

## 验收

对应 `docs/ROADMAP.md` 第四阶段：

1. 在 A 点躲到 1.4 米的箱子后面蹲下：从对面看不到你的头；站起来能看到并开枪。
2. 在高台栏杆后蹲下同理。
3. 选移动靶模式，走到横跳的假人旁边贴着它走动：你和假人都能活动，不会互相卡住。A 大宽 7 米、连接宽 5 米，人物直径 0.6 米，足够两三个人并排通过。
4. 预瞄模式从出生点出发，走 A 大进点，依次清掉所有假人。
